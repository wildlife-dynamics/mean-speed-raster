User Guide

How to load Mean Speed Raster, fill in its run form, and read the map it produces.

1. Load the workflow

In the workflow runner, add a new template using this repository's URL, then select Mean Speed Raster from the templates list.

2. Data sources

  • Access to an EarthRanger data source, set up as a connection.

3. Fill in the run form

The sections appear in this order. Sections marked advanced are hidden under the form's advanced options; their defaults work for most data.

Build Ecograph (advanced)

FieldDescriptionDefault
Step Length (m)The size of each grid cell, in meters. Pick one of two options:
  • Fixed value (m): you set the cell size. Must be between 500 and 100000.
  • Auto (use average step distance): the cell size becomes the average distance between consecutive GPS fixes in the view.
Smaller cells show more detail but take longer and leave more empty gaps between cells; larger cells give a smoother, coarser picture.		Fixed value, 2000

4. Read the map

  • Each cell shows the mean speed (km/h) of the track segments that start in it. Cells with no segments are left empty.
  • The legend lists five speed ranges from slowest (dark green) to fastest (red).
  • The ranges are equal-interval across each view's own speeds, so they differ between subjects. Compare colours within one view, and check the legend before comparing views.
  • Hover a cell to see its class.

5. Find the results

The dashboard opens when the run finishes. Each view's grid is attached to that view as a GeoParquet download. All files (the per-view grids and map HTMLs, plus the group's cleaned relocations and trajectories) are written to the results folder the runner gives the workflow (ECOSCOPE_WORKFLOWS_RESULTS).
